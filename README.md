# module_RDA5807m

Драйвер FM/RDS-приёмника **RDA5807M** для `avr-fota`: I2C, сканирование диапазона,
чтение RDS (PS-имя, время/дата 4A) и источник времени `core_sys`.

> **Статус: WIP, сейчас не работает. Разработка модуля приостановлена.**
>
> На реальном устройстве I2C (`0x11`), chip ID `0x5804` и перестройка по каналам
> работают, но скан не находит станций: `max_rssi ≈ 14`, `FM_TRUE` появлялся один
> раз кратковременно (92.4 МГц, RSSI 11). Нужно проверить RF-тракт и антенну.
> Таблица станций и RDS-время на железе пока не подтверждены.

## Что есть

- `module_RDA5807m_driver.*` — низкоуровневый драйвер RDA5807M.
- `module_RDA5807m_engine.cpp` — автомат сканирования, список до 12 станций, time source.
- `module_RDA5807m.cpp` — web, конфиг, ресурс `rda5807m.mode` (`auto/off`).
- `web/rda5807m.html` — статус и таблица станций (частота, RSSI, BLER, стерео, время, имя).

## Сборка

```bash
platformio run -e esp32-rda5807m
platformio run -e esp8266-rda5807m
```

ESP8266: модуль компилируется, но линковка env упирается в существующие
`undefined reference AsyncFSWebServer::on/onNotFound` (воспроизводится и без
этого модуля на `esp8266-veml7700`).

## Ограничения

- RDA5807M не измеряет SNR; в таблице показывается BLER (уровень ошибок RDS A/B).
- Для приёма обязательна антенна; без неё RSSI остаётся на уровне шума.
- RDS 4A передаётся раз в минуту; быстрый скан может не получить время.
- I2C используется по direct-access адресу `0x11`; полный доступ `0x10` не
  используется из-за конфликта с VEML7700.
