> **Статус: WIP, сейчас не работает. Разработка модуля приостановлена.**
> 2026-10-30: I2C (`0x11`), chip ID `0x5804` и перестройка по каналам работают,
> но живой скан не находит станций: `max_rssi ≈ 14`, `FM_TRUE` появился один раз
> кратковременно (92.4 МГц, RSSI 11). Требуется проверка RF-тракта/антенны;
> таблица станций и RDS-время на реальном устройстве пока не подтверждены.

> **Опциональный модуль.** Подключается через `src_filter` (define-флаг `MODULE_RDA5807M`
> выводится из `src_filter` автоматически, в `build_flags` его указывать не нужно).
> **Работоспособен только в составе сборки, содержащей ядро** (см. `../../TRS.md` §2.1).

Драйвер микросхемы RDA5807M (I2C) и источник времени системы по RDS-группе 4A.
Модуль сканирует FM-диапазон, хранит до 12 самых сильных станций и отдаёт
`core_sys` время UTC, полученное из RDS. На шину публикуется только режим
`rda5807m.mode` (`auto/off`); телеметрия станций доступна только на веб-странице.

- **Репозиторий:** https://github.com/Arcanum753/module_RDA5807m
- **Папка:** `src/module_RDA5807m/`
- **Флаг активации:** `MODULE_RDA5807M` (генерируется в `src/modules_defines.h` из `src_filter`)
- **Registry:** `object=module_rda5807m`, `define=MODULE_RDA5807M`, `namespace=rda5807m`,
  `web=1`, `loop=1`, `res=1`, `time_source=1`
- **Env:** `esp32-rda5807m`, `esp8266-rda5807m`
- **Только для платформы:** обе (ESP8266/ESP32)
- **Зависит от ядра:** `core_web`, `core_sys`, `core_json`, `core_state` (EERTOS — `core_sys/eertos.h`)
- **Зависит от модулей:** — (опрос идёт через `loop()` модуля)

## Назначение

- Низкоуровневый драйвер RDA5807M: питание, настройка, перестройка по каналам,
  чтение статуса и RDS-блоков A/B/C/D.
- Автоматический скан диапазона: поиск станций, сбор PS-имён, ожидание RDS-времени (4A).
- Источник времени `rda5807m` для `core_sys` (read-only, приоритет 40).

## Функциональные требования

- FR-RDA-1: Настраивать RDA5807M по I2C direct-access (`0x11`) и читать RSSI, стерео,
  BLER A/B, RDS-блоки.
- FR-RDA-2: Сканировать диапазон 87.5..108.0 МГц (band 0) с шагом 100 кГц; хранить до
  12 самых сильных станций.
- FR-RDA-3: Собирать PS-имя станции (группы 0A/0B) и время/дату из группы 4A.
- FR-RDA-4: Валидировать 4A (RDSS, BLER A/B, MJD 2020..2100, часы/минуты, offset) и
  отдавать UTC в `core_sys`.
- FR-RDA-5: Управление `auto/off`: `off` останавливает скан и обесточивает чип.
- FR-RDA-6: Веб-страница с таблицей станций (частота, RSSI, BLER, стерео, время, имя)
  и кнопками скана/режима.
- FR-RDA-7: Быстрый скан: имена для всех выбранных станций, время — у станции, давшей
  валидную 4A; следующие попытки по интервалу `scanIntervalS`.

## Аппаратные интерфейсы

| Интерфейс | Выводы по умолчанию | Примечание |
|-----------|---------------------|------------|
| I2C (RDA5807M) | ESP32 SDA=21/SCL=22; ESP8266 SDA=4/SCL=5 | `Wire`; адрес `0x11` (direct access). Полный доступ `0x10` не используется из-за конфликта с VEML7700 |

RDA5807M питается от 3.3 В. Аудиовыход не используется: чип работает с `DMUTE=0`
(mute), RDS-декодер включён. Между сканами и в режиме `off` чип переводится в power-down.
Для приёма обязательна антенна: без неё RSSI держится около 0..14 и `FM_TRUE` почти не
появляется, поэтому таблица станций будет пустой даже при исправном I2C. Подойдёт провод
50–75 см на вход ANT (или провод наушников, если он является антенной на плате модуля).

## Веб-интерфейс

| Метод | URL | Назначение |
|---|---|---|
| GET | `/rda/info` | JSON: режим, фаза/прогресс скана, счётчики, станции, последняя синхронизация, статус источника, ошибка I2C |
| POST | `/rda/scan` | `action=start` / `action=stop`; в режиме `off` — 409 |
| POST | `/rda/save` | `mode=0/1`, опционально `minRssi`, `scanIntervalS`, `scanOnBoot`; применить и сохранить |
| GET | `/rda/ver` | версия модуля |

Страница `rda5807m.html` (пункт меню — `web/_menu.html`), конфиг `web/config_rda5807m.json`.
Страница обновляется раз в 2 с через `/rda/info`; таблица — не более 12 строк.

## Конфигурация

`/config_rda5807m.json`:

```json
{"mode":0,"sda":-1,"scl":-1,"minRssi":28,"band":0,"stepKhz":100,"scanIntervalS":3600,"scanOnBoot":true}
```

- `mode` — 0 `auto`, 1 `off`.
- `sda`/`scl` — `-1` = платформенный дефолт.
- `minRssi` — программный порог RSSI (0..127); это **не** 4-битный `SEEKTH`.
- `band` — 0: 87.5..108; 1: 76..91; 2: 76..108; 3: 65..76 МГц.
- `stepKhz` — 100/50/200/25 кГц.
- `scanIntervalS` — период планового скана, 300..86400 с.
- `scanOnBoot` — запускать скан через 5 с после старта.

Результаты скана хранятся только в RAM и после перезагрузки теряются. Сохранение
конфига — только пользовательским путём (web) или bus-функциями `rda5807m.save` /
`rda5807m.save_mode`.

## Ресурсы шины (namespace `rda5807m`)

- `rda5807m.mode` — ENUM (`auto`/`off`), rw.
- функции: `rda5807m.mode` (→), `rda5807m.save` (→), `rda5807m.save_mode` (→).

Телеметрия (RSSI, станции, время) на шину не публикуется. `save_mode` сохраняет только
поле `mode`; `save` — полный конфиг (отложенно, через EERTOS).

## Источник времени

- Имя: `rda5807m`; приоритет: 40; read-only (`set = nullptr`).
- `get()` отдаёт UTC и добавляет секунды, прошедшие с момента приёма 4A
  (`_lastRdsEpoch + (millis() - _lastRdsMs)/1000`), иначе `core_sys` отклонит время
  как backward-jump.
- `status()`: `""` — ok; `"module off"`, `"i2c error"`, `"no rds time"`,
  `"rds time stale"`.
- Stale: `max(2 * scanIntervalS, 3600)` секунд.
- RDS offset из 4A используется только для отображения местного времени станции;
  системный часовой пояс задаёт `core_sys`.
- Время может отсутствовать, если самая сильная станция не передаёт 4A; следующий
  плановый скан повторит попытку.

## Ограничения

- RDA5807M **не измеряет SNR**; вместо SNR показывается BLER (уровень ошибок блоков A/B).
- Чтение RDS-блоков через direct access неатомарно: смешанные группы отбрасываются по
  BLER/типу группы/правдоподобности даты.
- PS декодируется как ASCII; EBU Latin/кириллица заменяются пробелом.
- Эпоха RDS ограничена 32-битным `time_t` (до 2038 года); более поздние даты
  отбрасываются как невалидные.
- Время 4A передаётся раз в минуту; быстрый скан может не получить его с первой станции.
- I2C-адрес `0x11` фиксирован; некоторые клоны могут не поддерживать direct access.
- `Wire.begin(sda, scl)` выполняется при первом скане; все I2C-модули должны использовать
  одинаковые SDA/SCL.
- Сканирование занимает до ~2 минут (band scan + имена + ожидание 4A) и выполняется
  неблокирующе, по 20 мс на тик.

## Тестирование

- Сборка: `pio run -e esp32-rda5807m`, `pio run -e esp8266-rda5807m`.
- Живое тестирование на реальной плате выполняет пользователь по чек-листу в плане
  реализации (I2C ACK `0x11`, `/rda/info`, режим `off/auto`, `/time/sources`,
  `time.sync_from=rda5807m`, отсутствие блокировки web).

## Критерии приёмки

- AC-RDA-1: оба env собираются; registry содержит модуль и `registerTimeSource()`.
- AC-RDA-2: страница показывает до 12 станций с частотой, RSSI, BLER, стерео, временем
  (если получено) и именем.
- AC-RDA-3: `rda5807m.mode` присутствует в `/state/catalog`; `auto/off` применяется и
  сохраняется.
- AC-RDA-4: `/time/sources` содержит `rda5807m`; после 4A время валидно,
  `time.sync_from=rda5807m` работает; `off`/stale дают корректный status.
