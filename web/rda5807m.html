RDA5807M — FM/RDS приёмник

Описание / Description
RU: Драйвер FM/RDS-приёмника RDA5807M. Модуль сканирует диапазон, показывает до 12 самых сильных станций и используется как источник времени системы по группе RDS 4A (UTC). RDA5807M не измеряет SNR: в колонке BLER показан уровень ошибок RDS-блоков A/B (0 — без ошибок, 3 — некорректируемо). В быстром скане имена собираются для всех станций, а время — у станции, от которой получена синхронизация.
EN: RDA5807M FM/RDS driver. Scans the band, shows up to 12 strongest stations and provides system time from RDS group 4A (UTC). The chip has no SNR register; the BLER column shows RDS block error level A/B. The fast scan collects names for all stations and time from the station that provides sync.
